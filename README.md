# claude-plugins

tenkoh が配布する Claude Code プラグイン集。

## 導入

Claude Code のプロンプトで、マーケットプレイスを一度だけ登録する。

```
/plugin marketplace add tenkoh/claude-plugins
```

あとは使いたいプラグインを入れる。

```
/plugin install hibiki@tenkoh
```

## プラグイン

| 名前 | 内容 |
|---|---|
| [hibiki](plugins/hibiki) | Claudeの応答をOpenAI API互換サーバーを使って音声再生するModsを追加する |
